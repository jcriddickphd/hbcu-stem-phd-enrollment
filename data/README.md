# Data

`derived/` holds the numbers behind every table and chart. They are small and committed to the repository.

The federal source files are large and freely available, so they are not included. Get them here:

| File | Where to get it |
|---|---|
| GSS public use files, 2019 to 2025 | NSF NCSES, ncses.nsf.gov, Survey of Graduate Students and Postdoctorates, data tables and public use files |
| GSS field crosswalk (Table A-6) | NSF NCSES GSS technical tables |
| IPEDS Completions | nces.ed.gov/ipeds, Completions survey component |
